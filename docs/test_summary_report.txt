========================================
7. PERFORMANCE CHARACTERISTICS
========================================

GEMM Algorithm:
--------------
- For 4×4 matrices: 16 output elements
- Each element: 4 multiply-accumulate operations
- Total operations: 64 MACs
- State machine overhead: 2 DMA reads + 1 DMA write per MAC
- Simulation time: ~5.3 microseconds for 4×4 GEMM

Address Calculation:
-------------------
- Row-major storage
- A[i][k] offset: (i × K + k) × sizeof(uint64_t)
- B[k][j] offset: (k × N + j) × sizeof(uint64_t)
- C[i][j] offset: (i × N + j) × sizeof(uint64_t)
